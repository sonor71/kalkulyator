# Kalkulyator — приёмка семян подсолнечника

Офлайн-приложение для Windows: расчёт скидок по пяти лабораторным показателям и зачётного веса партии семян.

## Как запустить

**Без установки:** скачайте исходники через **Code → Download ZIP**, распакуйте архив и дважды откройте файл **index.html**. Приложение работает в современном браузере без сервера, регистрации и интернета.

**Готовое приложение Windows:** откройте **Actions → Windows desktop build → последняя успешная сборка → Artifacts → Kalkulyator-Windows**, скачайте ZIP, распакуйте **Kalkulyator-1.0.0-Windows.exe** и запускайте его. Это переносимая Windows-программа, установка не требуется. Сборка запускается после push в main.

**Для разработчика:**
- Node.js 22+
- npm install
- npm test
- npm start — запуск Electron
- npm run dist:win — создание Windows portable EXE (лучше на Windows)

## Рабочий процесс

1. Откройте **Настройки качества**. Правила первого показателя «Влажность» заполнены по исходному изображению. Остальные четыре названия и формулы **не были переданы** — их необходимо ввести после уточнения у заказчика.
2. Для каждого показателя укажите название, единицу, коридор без скидки, допустимый минимум/максимум (необязательно), интервалы ниже/выше нормы и ставки **в процентных пунктах скидки за единицу показателя**.
3. Включите «Активировать правила» у всех пяти показателей и нажмите «Сохранить правила».
4. В разделе **Расчёт партии** введите исходный вес и пять результатов лаборатории. Доступны дробные значения с точкой или запятой.
5. После расчёта сохраните запись или распечатайте акт. В **Журнале расчётов** доступны просмотр детализации, повторная печать, CSV-экспорт, резервное копирование/восстановление JSON и удаление записей.

Правила и журнал сохраняются **локально на устройстве** (localStorage), не отправляются в сеть. При переносе на другую машину используйте JSON-резервную копию. Браузерная и EXE-версии могут использовать **разные локальные хранилища**; они не синхронизируются.

## Формула из заказа: влажность

| Влажность | Расчёт |
| --- | --- |
| Ниже 4% | Вне приёмки; расчёт запрещён |
| 4–6% | 2,5% скидки за единицу ниже 6% |
| 6–8% | Скидка 0% |
| 8–12% | 1% за единицу выше 8% |
| 12–15% | +1,5% за единицу сверх 12% |
| 15–20% | +2% за единицу сверх 15% |
| Выше 20% | +3% за единицу сверх 20% |

Расчёт **накопительный**. При влажности 20%: (12−8)×1% + (15−12)×1,5% + (20−15)×2% = **18,5%** скидки. Для партии 100 кг при нулевых скидках по остальным показателям: 100×(1−0,185) = **81,5 кг** зачётного веса.

**Моменты для обязательного согласования с заказчиком:**
- В описании заказа указано «100 кг → ~87 кг», но пример влажности 20% даёт 81,5 кг уже только по одному показателю. Эти данные несовместимы для одинакового набора значений.
- Фраза про влажность 4–6% не поясняет точку отсчёта: реализовано от 6% вниз.
- Неизвестны названия, диапазоны, формулы четырёх других лабораторных показателей.
- Не подтверждено, что скидки по всем пяти показателям должны суммироваться до вычета из физического веса. В текущей реализации принято такое правило для расчёта.

Проект **не приписывает отсутствующим показателям выдуманные коэффициенты**: при незаполненных/неактивных правилах финальный расчёт блокируется. При скидке свыше 100% расчёт блокируется.

## Тесты

Команда **npm test** проверяет граничные и дробные значения влажности, 20% → 18,5%, отклонение при влажности ниже 4%, совокупные скидки, неполные правила и скидку свыше 100%.

## Технологии

Без внешних API и зависимостей для расчёта: HTML, CSS, JavaScript, чистое математическое ядро **calculator.js**; Electron используется только для упаковки в Windows EXE.
